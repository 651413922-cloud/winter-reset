### Bug 修复 #1: Windows subprocess 编码问题
- **根因**: Windows 下 `subprocess` 的 `text=True` 默认用 GBK 解码，tshark 输出 UTF-8 中文网卡名导致 `UnicodeDecodeError`，stdout 变 None
- **修复**: 改用 `text=False` (二进制模式) + 手动 `.decode("utf-8", errors="replace")`
- **影响**: `get_wlan_index()`, `start_tshark()`, 主循环逐行读取
